# 実務ガイド：無料モニタリング後の「2つのアンケート調査」実施マニュアル
### ーー 施策の「改善効果（Before/After）」の測定と、本契約に向けた「顧客フィードバック」の回収 ーー

無料モニター（実証実験）の終了後には、次のアクションへ進むために**2つの異なる目的のアンケート調査**を実施する必要があります。

1.  **追跡サーベイ（従業員向け）**：改善施策の実施前後で、生産性損失（プレゼンティーズム）がどれだけ減ったかを測定する。
2.  **顧客満足度調査（担当者・経営陣向け）**：アンケートやレポートの価値、有料契約への移行意向を聞き取り、セールスフックにする。

本ドキュメントは、この2つのアンケートの設計と具体的な文面・設問の一覧です。

---

## 📈 Part 1：改善効果を測定する「追跡（Before-After）サーベイ」

最初の調査（1回目）から、職場環境改善や専門家セミナーなどの「施策」を導入した後、**約1〜1.5ヶ月後**に同じアンケートを再度実施し、効果を測定します。

### 1. 従業員への「2回目（追跡）アンケート」案内メッセージテンプレート
一度アンケートに答えている従業員に対し、今回の目的（施策の効果測定）を説明して協力を促す文面です。

```text
件名：【ご協力のお願い】第2回 職場環境と健康に関するアンケート調査（回答時間約2分）

従業員の皆様へ

お疲れ様です。[部署/役職]の[名前]です。

先月は「職場環境と健康に関するアンケート」にご協力いただき、誠にありがとうございました。

前回の結果に基づき、弊社では[施策内容（例：エルゴノミクスチェアの試験導入 / オンライン姿勢改善セミナーの実施）]を導入いたしました。

今回は、これらの取り組みによって**「職場環境や皆様の体調、仕事のしやすさにどのような変化があったか」を測定・検証するため、第2回（追跡）アンケート**を実施いたします。

より働きやすい職場づくりを進めるための大変重要なデータとなりますので、度々のお願いとなり恐縮ですが、再度ご協力をお願い申し上げます。

■ アンケート回答URL（スマホ・PC対応）：
👉 [貴社専用のURL（例：https://.../?company=A社_2回目）]

■ 回答期限：[月][日]（[曜日]）まで
■ 回答時間：約2分（前回と同様の短い設問です）
※無記名での回答（ID入力任意）となっており、評価やプライバシーに影響することは一切ありません。本音でのご回答をお願いいたします。
```

### 2. Before / After データ比較のロジック（効果の証明）
1回目と2回目の結果をダッシュボードやスプレッドシートで比較し、削減できた「損失額」を算出します。

*   **削減損失額（ROI）の計算式**：
    $$\text{改善による削減コスト/年} = \text{1回目の合計損失額/年} - \text{2回目の合計損失額/年}$$
*   **事例化の表記例**：
    > 「腰痛対策セミナーの実施により、首・肩・腰の痛みを訴える割合が42%から28%へ低下。営業部全体のプレゼンティーズムによる年間想定損失額が**約240万円削減（改善）**されました。」

実証実験に協力してくれた「人事担当者」や「経営陣（CFO等）」からフィードバックを得るためのアンケートです。本契約（有料販売）に向けた営業フックや、将来の「お客様の声（導入実績）」として活用します。

*   **選択肢**：[ 非常に役に立った / 役に立った / あまり役に立たなかった / 全く役に立たなかった ]

#### Q3. 今後、本サービス（有料版）を継続・導入する場合の予算感について
*   **設問**：もし今後、このサーベイシステムを定期的な組織診断ツールとして継続導入（年4回の実施など）する場合、月額（または1回あたり）いくら程度であれば導入を検討できますか？
*   **選択肢**：
    - [ 月額 1万円〜3万円程度（小規模向けサブスク） ]
    - [ 月額 3万円〜5万円程度 ]
