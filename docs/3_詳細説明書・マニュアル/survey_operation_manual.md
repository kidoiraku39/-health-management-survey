## 第1部：導入前ヒアリング「聞き取りトークリスト」

モニター打診時や、キックオフの最初の面談で顧客企業（主に人事責任者や経営陣）の「真のニーズ」を引き出すためのヒアリングシートです。

### 1. 現状の組織課題と期待する効果のヒアリング
健康経営に取り組む「大元の動機」をクリアにし、レポート作成時に焦点を当てるポイントを特定します。

*   **トーク例**：
    > 「現在、貴社において従業員の皆様の健康課題や、それに伴う生産性への影響について、何か懸念されている点（肩こり・腰痛の多さ、眼精疲労、睡眠不足、プチメンタル不調など）はありますか？」
*   **深掘り質問**：
    - 特にどの部署（営業、エンジニア、管理部門など）でその傾向が強く見られますか？
    - 従業員の平均年齢、男女比、および働き方（リモートワーク率、オフィス出社率）はどのくらいでしょうか？

### 2. 過去の取り組みと従業員の巻き込みやすさの確認
アンケートを配った際にどれくらい協力が得られそうかを事前に予測し、周知方法を調整します。

*   **トーク例**：
    > 「これまでに社内で健康に関するアンケートや、その他の意識調査などを実施されたことはありますか？ その際の回答の集まり具合（回収率）や、従業員の皆様の反応はいかがでしたでしょうか？」
*   **深掘り質問**：
    - 現在、会社として提供している健康支援（オフィスでの整体優待、産業医面談、フィットネス補助など）は何かありますか？

### 3. 今回のデータ活用・経営報告におけるゴールの確認
作成する「診断レポート」を、誰に対して、どのような意思決定の材料として使うかを合意します。

*   **トーク例**：
    > 「今回のサーベイ結果（可視化された年間損失額や環境改善要望）は、社内でどのように活用される予定ですか？ 例えば、経営会議での報告、CFOへの予算獲得、あるいは『健康経営優良法人』の認定申請用でしょうか？」

## 第2部：サーベイ実務運用マニュアル

導入が決定した後、アンケートを配信して高い回収率で回収し、レポートを提出するまでの人事担当者向け（および自社のサポート用）の運用手順です。

```
【運用フロー全体像】
┌──────────────┐      ┌──────────────┐      ┌──────────────┐
│ ① 準備フェーズ│ ──►  │ ② 周知・回収 │ ──►  │ ③ 分析・報告 │
└──────────────┘      └──────────────┘      └──────────────┘
 ・URLの発行          ・周知メール送信        ・社内ダッシュボード分析
 ・スケジュールの確定    ・回収率の中間管理      ・診断レポート作成・面談
```

### 1. 準備フェーズ（実施の1週間前）
1.  **専用URLの発行**：
    - 企業専用のパラメータ付きアンケートURL（例：`https://.../?company=A社`）を用意します。
2.  **実施スケジュールの確定**：
    - 回答期間は **1週間〜10日間** が最適です（長すぎると後回しにされ、回答率が下がります）。
    - 配信日は、業務が比較的落ち着いている **火曜日の午前中** や **水曜日の朝** を推奨します。

### 2. 周知・回収フェーズ（実施中）
1.  **初回アナウンス（実施初日）**：
    - 社内メールやSlack/Teamsなどの全体チャンネルで告知します。
    - **ポイント**：従業員が「評価に響くのでは？」「個人の回答が上司に筒抜けになるのでは？」と不安にならないよう、**「無記名で回答可能であり、データは統計的に処理されること」**を強く伝えます。
    - 告知には、作成済みの「[従業員向け案内マニュアル](file:///C:/Users/kidoi/.gemini/antigravity/brain/01b7d727-ec60-4eea-937a-3410e5c57a5c/employee_guide.md)」のテンプレートをそのままご使用ください。
2.  **中間リマインド（実施5日目）**：
    - 回収率が50%を下回っている場合、人事部から「2分で終わる手軽さ」を再度強調して未回答者に回答を促します。
    - **目標回収率**：有効な組織分析を行うため、**全従業員の70%以上**の回答を目標とします。

### 3. 分析・報告フェーズ（実施完了後）
1.  **社内ダッシュボードでのデータ確認と分析**：
    - 回答期間が終了したら、**社内用集計ダッシュボード**（自社のみが閲覧できる管理画面）にて回答データを分析します。※顧客企業へダッシュボードの直接アクセス権は渡しません。
2.  **組織健康診断レポートの作成**：
    - ダッシュボードの分析結果をベースに、顧客企業向けの「組織健康診断レポート（報告用スライドまたはPDF）」を作成します。QQ-methodに則った「組織全体の年間損失額」「部署ごとの不調傾向」「職場環境への改善要望」をわかりやすく資料化します。
3.  **フィードバック面談（レポート報告会）の実施**：
    - 顧客企業の人事・経営陣とオンライン等で振り返り面談を行い、診断レポートを提示します。最も深刻な課題に対する専門家プログラム（姿勢指導ストレッチ等）やエルゴノミクス投資（椅子の買い替え等）の改善ロードマップを提示し、次の有料アクションへと繋げます。
