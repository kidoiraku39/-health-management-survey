# 実務ガイド：集計ダッシュボードを「診断レポート」に変換・作成する手順

本ドキュメントは、アンケート回答完了後、社内用ダッシュボードに集計されたデータをクライアント企業へ提出する「組織健康診断レポート（報告書）」へ落とし込むための具体的な3つの作業手順（アプローチA、B、C）を文章化したマニュアルです。

---

## 🛠 アプローチA：Googleスライドによる「提案用レポート」作成手順
見栄えが最も美しく、クライアントの経営陣やCFO（財務責任者）へのプレゼンテーションに最も適した方法です。

### 1. 準備フェーズ
- **テンプレートスライドの用意**：
  あらかじめGoogleスライドで、表紙・目次・データ枠がデザインされた「テンプレートスライド」を1つ作成し、マスターとして保管しておきます。
  （※スライド構成は、作成済みの「[修正版スライド原稿](file:///C:/Users/kidoi/.gemini/antigravity/playground/final-photosphere/survey-app/docs/2_営業提案・打診/revised_slide_deck.md)」をベースにします）

### 2. データ取得と切り取り（キャプチャ）
1. 管理者用URL（`https://.../?admin=true`）から社内用ダッシュボードにアクセスします。
2. 画面上に表示されている「部署ごとの生産性低下率グラフ」や「症状別の割合円グラフ」を確認します。
3. Windowsの標準ツール **「Snipping Tool（Windowsキー ＋ Shift ＋ S）」** を起動し、グラフの境界線に沿ってドラッグし、画像をクリップボードにコピーします。

### 3. スライドへの流し込みとコメント追記
1. Googleスライドの該当するデータ枠に、コピーしたグラフ画像を貼り付けます（Ctrl + V）。
2. ダッシュボードから「全社合計損失額（年間）」や「平均パフォーマンス低下率」の数値を読み取り、スライドのテキスト部分に転記します。
3. 従業員の職場改善要望（Q6-1の生の声）の中で、経営陣に伝えるべき代表的なコメント（例：「椅子が古く腰痛が多発している」等）を3〜5個抽出し、スライドにテキストとして記載します。

### 4. エクスポートと納品
- 完成したスライドを「ファイル ＞ ダウンロード ＞ PDFドキュメント」でエクスポートし、報告書として顧客にメール送付、または会議室のモニターに投影して対面で報告します。

## 📊 アプローチB：Googleスプレッドシートの「自動集計PDF」作成手順
手作業によるデータ転記の手間を極限まで減らし、アンケート終了と同時にほぼ自動でレポートを完成させる手順です。

### 1. 印刷用「レポートシート」の設計（初回のみ）
1. 回答データが蓄積されるスプレッドシート内に、回答用の生データシートとは別に「レポート出力用」のシートを新規作成します。
2. `AVERAGE` や `COUNTIF` などのスプレッドシート関数を使い、生データから「部署ごとの平均低下率」や「各症状の発生件数」を自動計算する表を作成します。
3. スプレッドシートのグラフ挿入機能を用いて、その集計表と連動した円グラフや棒グラフを作成し、シート内に配置します。
4. シートのレイアウト（フォントサイズ、セルの背景色、枠線）を、A4サイズ1〜2枚に綺麗に収まるように整えます。

### 2. 回答締め切り時の作業
1. アンケート回答の締め切り後、スプレッドシートを開き、作成した「レポート出力用」シートを表示します。この時点で、データは関数によって最新の回答結果に自動更新されています。
2. 自由記載欄（Q6-1、Q8）のテキストを確認し、不要なノイズデータを取り除いてシート内の「自由記載一覧」に反映させます。

### 3. PDFの出力
- 「ファイル ＞ 印刷」を選択し、印刷設定で「用紙サイズ：A4」「向き：横（または縦）」「シートを1ページに合わせる」を設定し、PDFファイルとして保存・エクスポートします。

## 🤖 アプローチC：Geminiを活用した「AI分析コメント」生成手順
ダッシュボード上の数値から、「どのような課題があり、どう対策すべきか」という説得力のある分析テキストをGemini（AI）に自動生成させる、コンサルティング重視の手順です。

### 1. データのコピー
- 管理者用ダッシュボード、またはスプレッドシートから、以下の代表的なデータをテキストとしてコピーします。
  - 各部署の回答数と平均損失率（％）
  - 最も多かった症状トップ3（例：1位 首・肩のこり、2位 睡眠不足）
  - 従業員から寄せられた職場環境への不満テキスト（Q6-1）

### 2. Geminiへの指示（プロンプト実行）
Gemini Advanced（またはGemini Canvas）を開き、以下のプロンプトを入力して送信します。

> **コピペ用プロンプトテンプレート**：
> ```text
> あなたはプロフェッショナルな健康経営コンサルタントです。
> 以下のアンケート集計結果をもとに、この企業の経営陣に向けた「組織健康診断レポートの総合分析コメント」および「生産性向上のために今すぐ取り組むべき2つの改善施策の提案」を、客観的かつ論理的な文章で作成してください。
> 
> 【データ】
> - 組織全体での年間推定生産性損失額：〇〇万円
> - 最も多い不調：1位 首・肩のこり（〇％）、2位 睡眠不足（〇％）
> - 最も損失の大きい部署：〇〇部（平均損失率〇％）
> - 従業員からの主な作業環境への不満：
>   （ここにQ6-1の改善要望テキストを3〜4個コピペ）
> ```

### 3. コメントの反映
- Geminiから出力された論理的で説得力のある分析文・対策提案をコピーし、アプローチAの「報告スライド」のアナリストコメント欄、またはアプローチBのレポートPDF内に貼り付けて報告書を完成させます。
