### ーー 従業員の健康課題による生産性損失を「円」で見える化し、ROIの高い健康経営へ ーー

---

## 1. はじめに：健康経営における「真の課題」とは
現在、多くの企業が健康経営に取り組んでいますが、その多くが「アブセンティイズム（欠勤・休職）」の対策に留まっています。
しかし、健康関連コストにおいて本当に解決すべきなのは、**「プレゼンティーズム（疾病就業：体調不良を抱えながら出勤し、パフォーマンスが低下している状態）」**です。

```
【企業の健康関連コストの構成比】
┌───────────────────────────────────────────────┐
│ ■ プレゼンティーズム（見えない生産性損失）   : 約73%  │
├───────────────┬───────────────────────────────┤
│ ■ 医療費 : 17% │ ■ アブセンティイズム（欠勤）: 10% │
└───────────────┴───────────────────────────────┘
```
※出典：健康関連コストにおけるプレゼンティーズムの割合に関する研究

本サービスは、この見えない「プレゼンティーズム損失額」を学術的根拠に基づいて精密に測定し、具体的な改善アクション（投資対効果の高い施策）を特定する、次世代の健康経営サーベイです。

## 2. 生産性損失額の算定ロジック（学術的背景）
本サーベイは、厚生労働省が推奨する学術的な健康経営測定基準である**「QQ-method（Quantity and Quality法）」**および**「SPQ（Single-Item Presenteeism Question）」**のダブルエンジンで損失を算定します。

### ① 主症状による年間損失額（QQ-method）
従業員が「現在、最も仕事に影響している健康問題（主症状）」を選択し、その有症状時の仕事の「量」と「質」を10段階で自己評価した数値から、損失割合と年間損失額を論理的に計算します。

$$\text{生産性低下割合} = 1 - \frac{\text{仕事の量}(0\text{-}10) \times \text{仕事の質}(0\text{-}10)}{100}$$

$$\text{生産性損失額/年} = \text{時間単価}(3,300\text{円}) \times 8\text{時間} \times \text{生産性低下割合} \times \text{過去3ヶ月の有症状日数} \times 4\text{（年間換算）}$$
*   ※時間単価は健康経営評価における日本標準単価（3,300円/時）を採用しています。

### ② 全般的なパフォーマンス低下による損失額（SPQ）
主症状の有無に関わらず、過去4週間における全般的な仕事のパフォーマンス（0%〜100%）を測定し、個人の「想定年収（または標準給与）」と連動させて、経営全体のパフォーマンス低下による金銭的損失を算定します。

## 3. アンケート（設問設計）の詳細
従業員の回答負担を最小限（スマホで約2分）に抑えつつ、質の高いデータを収集するために設計された7つの設問構成です。

| 設問番号 | 調査項目 | 設問の意図と特徴 |
|---|---|---|
| **Q1** | 全般的なパフォーマンス評価 | SPQに準拠し、全般的な生産性低下率を測定（年収連動損失のベース）。 |
| **Q2** | **主症状の特定（単一選択）** | **「現在仕事に最も影響している主症状（1つ）」**を特定します（赤太字で強調表示）。<br>※「不調なし」の場合はQ3〜Q5をスキップして回答負担を軽減。 |
| **Q2-sub** | 主症状以外の不調（複数選択） | 主症状の影に隠れている、現在仕事や生活に影響しているすべての不調を網羅します。 |
| **Q3** | 有症状日数（過去3ヶ月） | 過去3ヶ月間で、その症状を感じながら仕事をした日数を測定。 |
| **Q4 / Q5** | 症状発生時の仕事の「量」と「質」 | 症状がある日の作業効率を10段階（0〜10）で自己評価し、QQ法に基づき損失率を算出。 |
| **Q6 / Q6-1** | 作業環境（エルゴノミクス）の評価 | オフィス環境（机、椅子、照明、温度等）への不満と、具体的な改善要望テキストを取得。 |
| **Q7** | 希望する専門家介入プログラム | ストレッチセミナー、姿勢改善、メンタルケアなど、従業員が「今求めている施策」を特定。 |

## 4. 提供するアウトプット（成果物）

### 📊 ① 人事・経営向け「組織集計ダッシュボード」（リアルタイム連動）
従業員が回答を送信すると、Googleスプレッドシート（GAS）を経由し、即座に組織用ダッシュボードに反映されます。

*   **部署ごとの不調割合・損失額の比較**：どの部署に優先的なアプローチが必要か一目で判別。
*   **環境改善要望のテキストマイニング**：従業員の物理的環境への不満（椅子が合わないなど）を自動集計し、オフィス投資の判断材料を提供。
*   **推奨施策バナーの表示**：「目の不調 ✕ 照明の不満」など、特定の不調と環境不満が重なった際に、最適な改善セミナー等のバナーをダッシュボード上で自動的にレコメンド。

### 📄 ② 従業員向け「個人健康診断レポート」（即時フィードバック）
回答を送信した従業員本人に対し、その場で以下のパーソナルフィードバックが表示されます。

*   **あなたの年間推定損失額（可視化）**：自身の健康状態が仕事に与えているインパクトを自覚。
*   **セルフケア・改善アドバイス**：選択した不調に合わせた具体的なストレッチ法や、生活習慣の改善アドバイスを提示し、セルフケアを促進。

## 5. セキュリティとプライバシー保護について
健康や不調に関する繊細な個人データを取り扱うため、以下の通り強固なプライバシー対策を実施しています。

*   **無記名回答・ID入力の任意化**：
    従業員IDの入力は「任意（スキップ可能）」としており、個人が特定されない心理的に安全な環境で本音の回答を促します。
*   **データの暗号化とセキュアなデータ連携**：
    アンケート回答データはSSL/TLSによって暗号化された状態で通信され、安全なGoogle Apps Script（GAS）を通じて、貴社専用のGoogleスプレッドシートにのみ蓄積されます。
*   **CORSセキュリティ制限のクリア**：
    ブラウザのセキュリティ制限（CORS）をクリアする最新の通信設計を採用しており、企業のイントラネット環境や多様なブラウザから安全にアクセス可能です。

## 6. 実証実験（モニター）の実施フローとスケジュール
実証実験の導入から診断レポートの提出まで、すべて弊社側で手厚く伴走サポートいたします。

```
【導入から改善提案までの4ステップ】

STEP 1. 準備・設計（期間：約1週間）
 └ 貴社専用のアンケートURLの発行
 └ 周知マニュアル（メールひな形）の送付

STEP 2. アンケート実施（期間：約1〜2週間）
 └ 従業員様へURLの配信（スマホ・PCから回答可能）
 └ 目標回収率（70%以上）に向けた回答進捗のモニタリング

STEP 3. データ集計と分析（期間：即時〜数日）
 └ ダッシュボードにて速報値の確認
 └ 弊社専門スタッフによるデータのスクリーニングと組織傾向の分析

STEP 4. 診断レポートのご提出（期間：実施後1週間以内）
 └ 「組織健康診断報告書」のご提出
 └ 課題に対する具体的な改善施策（専門家介入等）のROIシミュレーション提案
```
