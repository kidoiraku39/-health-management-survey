# モニター候補企業への「実証実験（モニター）打診用・文章テンプレート」

本ドキュメントは、モニター候補企業のアプローチ時（メール、Slack、Teams、Messenger等）にそのままコピー＆ペーストして使用できる文章テンプレートです。相手との関係性や連絡ツールに合わせて使い分けてください。

---

## ✉️ テンプレート1：メール用（フォーマル・紹介用）
やや堅めの関係性の企業や、他者から紹介された企業に対して、メールで正式に提案・打診する際に使用します。

```text
件名：【無償モニター募集】従業員の「健康による生産性損失（円）」を可視化する調査のご案内

[企業名]
[役職] [お名前] 様

いつも大変お世話になっております。
[あなたの会社名 / ご自身の名前] でございます。

本日は、貴社の健康経営および従業員の皆様の生産性向上に貢献できる「実証実験（無料モニター）」のご提案についてご連絡いたしました。

昨今、多くの企業において「従業員の心身の不調による生産性低下（プレゼンティーズム）」が大きな経営課題となっています。
これは「欠勤」とは異なり、肩こり・睡眠不足・眼精疲労などを抱えたまま出勤し、作業効率が著しく低下している状態で、実は企業の健康関連コストの約70%を占めると言われています。

そこで弊社では、この「隠れた生産性損失」を具体的な「円」で見える化し、効果的な対策を導くための【次世代健康生産性サーベイ】を開発いたしました。

本年[月]の本リリースに先立ち、現在、限定3〜5社様を対象とした「無料実証実験（モニター）」のご協力を募集しております。

■ モニター企業様への3大特典（完全無償）：
1. 組織健康診断レポートの作成・贈呈（貴社の年間推定損失額を試算）
2. 従業員へのオフィス環境（机・椅子等）への改善要望の自動集計
3. 課題に応じた専門家（整体師・理学療法士等）による改善アクションプランの提案

■ 貴社にお願いすること：
- 従業員の皆様に、スマホまたはPCから簡単なWebアンケート（約2分）へご回答いただくのみです（ID入力任意・プライバシー保護徹底）。

詳細をまとめた紹介資料（Googleスライド）を添付いたしますので、ご一読いただけますと幸いです。

まずは10〜15分程度、オンラインにて概要をご説明するお時間をいただけますでしょうか。
ご検討のほど、何卒よろしくお願い申し上げます。

--------------------------------------------------
[署名]
--------------------------------------------------
```

## 💬 テンプレート2：ビジネスチャット用（カジュアル・既存の関係）
Slack、Teams、Messengerなどで、既存のクライアントや知人の経営者・人事担当者へカジュアルに打診する際に使用します。

```text
[お名前]さん、お疲れ様です！[ご自身の名前]です。

本日は、現在弊社で開発している「健康経営アンケートツール」の無料モニター（実証実験）について、[お名前]さんの会社にぜひご協力いただけないかと思い、ご連絡しました。

最近、健康経営や従業員の生産性向上に取り組む企業が増えていますが、
「肩こり、腰痛、睡眠不足などで、出社しているけれど仕事の効率が落ちている（プレゼンティーズム）」
という見えない損失が、実は非常に大きいことが分かっています。

今回開発したツールは、厚生労働省推奨の基準に準拠し、その「見えない損失額」を具体的な「円（年間〇〇万円など）」として可視化し、どこにオフィス投資（机や椅子の変更など）をするべきかを特定できるものです。

本リリース前に、数社限定で「完全無料」のモニターを募集しております。

■ モニターのメリット：
・従業員全体の健康課題と年間損失額をまとめた「組織診断レポート」を無料で作成します。
・従業員がオフィス環境に抱いている本音の要望を集計します。

■ お願いしたいこと：
・メンバーの皆さんに、スマホで2分ほどで終わる簡単なアンケートに答えてもらうだけです。（※名前や社員IDの入力は任意なので、プライバシー面も安心です）

もしご興味を持っていただけそうであれば、まずは10分ほどオンラインでサクッと画面イメージや資料をお見せしながらご説明したいのですが、いかがでしょうか？

詳細資料もこちらに添付（またはリンク）しておきますので、お手すきの際にご覧ください！
よろしくお願いいたします！
```
