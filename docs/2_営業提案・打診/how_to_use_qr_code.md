# 実務ガイド：アンケート用URLをQRコード化して配布する方法
### ーー スマートフォンからの回答率を高めるための、QRコード作成手順とオフィス掲示用テンプレート ーー

アンケートをスマートフォンから簡単に回答してもらうために、アンケートURLをQRコード化して配布することは極めて有効です。特にオフィスの休憩スペースや会議室、掲示板等にQRコード付きのポスターを貼っておくことで、回答率を劇的に高めることができます。

---

## 🛠 1. QRコードのカンタンな作成手順

### アプローチA：Google Chromeブラウザの標準機能で作成する（最も簡単・早い）
特別なソフトやサイトを使わず、ブラウザだけで10秒で作成できます。

1. パソコンのGoogle Chromeで、対象企業用のアンケートURL（例：`https://health-management-survey.vercel.app/?company=A社`）を開きます。
2. アドレスバー（画面最上部のURLが表示されている場所）の右端にある **「共有（上矢印のアイコン）」** をクリックします。
3. 表示されたメニューから **「QR コードを作成」** を選択します。
4. 画面中央にQRコード画像が表示されるので、**「ダウンロード」** ボタンをクリックしてパソコンへ保存します。

---

## 📄 2. オフィス掲示用「QRコード付き案内ポスター」構成テンプレート

ポスター（A4サイズなど）をPowerPointやCanva、Word等で作成し、オフィスに印刷して掲示する際のデザイン構成案です。そのまま文章をコピーしてご活用ください。

```text
================================================================================
【ポスター中央上部：大見出し】
たったの 2分！
「働きやすい職場づくり」のための健康経営アンケート実施中

【中央部：説明文】
従業員の皆様が、日々の業務を健康でいきいきと進められる環境を整えるため、
現在の「体調（肩こり・腰痛・睡眠など）」や「職場環境への要望」に関する調査を行っています。

皆様の本音の声を参考に、オフィス環境の改善や専門家によるサポートを具体的に検討します。
ご協力のほど、よろしくお願いいたします。

【ポスター中央：QRコードの配置スペース】
┌───────────────────────────────────────────────┐
│                                               │
│             ここにダウンロードした            │
│            QRコード画像を大きく貼り付け       │
│                                               │
└───────────────────────────────────────────────┘
スマホのカメラをかざすと、すぐに回答画面が開きます。

【ポスター下部：注意事項と期限】
■ 回答期限：[月][日]（[曜日]）まで
■ プライバシーの保護について：
回答データは統計的に処理され、個人の回答内容が上司や会社に直接知られることはありません。
従業員IDの入力も「任意（スキップ可能）」ですので、安心してお答えください。
================================================================================
```

## 💡 運用のコツ：どこに掲示すると回答率が上がるか？

*   **オフィスの「共有スペース」**（リフレッシュルーム、給湯室、電子レンジやコーヒーメーカーの横）：
    ちょっとしたスキマ時間（2分程度）にその場でスマホを取り出して回答しやすくなります。
*   **各会議室のテーブル中央**：
    会議の開始前や、次のミーティングを待つわずかな時間に回答を促すことができます。
*   **配布用チラシとして手渡し**：
    総務や人事の担当者が、社内便や資料と一緒にペーパーで各従業員に配布するのも有効です。
